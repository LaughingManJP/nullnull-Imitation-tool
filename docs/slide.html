NullSlide に写真を送る

PC の Chrome / Edge から、USB ケーブルで StopWatch へ

スマホからなら、本体の Wi-Fi で送るほうがかんたんです(本体のボタン B の設定 →「Wi-Fi で受け取る」)。

このブラウザは USB の機器とつなぐ機能(Web Serial)に対応していません。PC の Chrome か Edge で開いてください。

つなぎ方

  1. 本体のメニューで NullSlide を選んで動かす
  2. USB ケーブルで PC につなぐ(Arduino IDE のシリアルモニタは閉じておく)
  3. 下の 本体につなぐ を押して、出てきた一覧から本体を選ぶ

つなぐたびに本体がメニューに戻ってしまうときは、NullMenu ではなく NullSlide_v7 を単体で書き込んでから送ってください。

つながっていません

本体の容量

—

写真は 400 枚まで入ります。ただし容量(約 9.7MB)は GIF と分け合うので、GIF が多いときや、写真が大きいときは、それより少なくなります。

スライドショーの設定

押すとすぐ本体に伝わって、本体にしまわれます。本体のボタン(B)で開く設定と同じものです。「形」は写真にかぶせる窓の形です(「そのまま」は画面いっぱいに見せる)。送った写真そのものは変わりません。

写真を送る

ここに 写真を落とす(またはクリックして選ぶ)
何枚でもまとめて送れます。送った順に並びます

写真はこのページで画面の大きさ(StopWatch なら 466×466 くらい)に縮めて、JPEG にしてから送ります。1枚 30〜80KB くらいです。JPEG / PNG / WebP などが送れます(iPhone の HEIC は、Chrome では読めないので JPEG にしてから)。

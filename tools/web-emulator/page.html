本体

傾き(加速度センサー)

x +0.00 y +0.00 ドラッグ、または矢印キー。ダブルクリックで水平に。

傾きで動くのは NullFloat 〜 NullBokeh の9作品(NullZen は除く)と NullChronicle、NullGalaxy、NullCloud、NullSapiens、NullSunset、null菩薩の「映る菩薩」です。

マイク(NullGoodbye)

NullGoodbye は音に合わせて動きます。マイクを使うか、手元の音声ファイルを「マイクの音」として聞かせてください。どちらも選ぶと NullGoodbye が音を聞く状態で起動し直します。何も選ばなければ、本体と同じく自動の振り付けで動きます。

GIF(NullGif)

エミュレータの本体に GIF を入れて、NullGif で流します(このページを閉じると消えます)。本物の StopWatch へは、NullGif の設定の「USB メモリになる」で PC から入れるか、スマホから本体の Wi-Fi で送ります。

写真(NullSlide)

エミュレータの本体に写真を入れて、NullSlide でスライドショーにします(このページを閉じると消えます)。本体の設定は B で開きます。本物の StopWatch へは、NullSlide の設定の「USB メモリになる」で PC から入れるか、スマホから本体の Wi-Fi で送ります。

電池

80%

メニューの上に電池の残りが出ます。作品の最中は、15% 以下(充電していないとき)だけ画面の下に赤い電池の絵が出ます。本体は電池を数秒ごとに読むので、変えてから出るまで少しかかります。

Serial モニタ

速さ(fps)はこのPCでの値です。本体の速さの目安にはなりません。

非公式のファン作品です。パビリオン「null²」とその制作者、大阪・関西万博の関係者・権利者とは一切関係がなく、許諾も受けていません。実物の映像・音声・データは使っておらず、画面に出るものはすべてその場で計算しています。

本体(M5Stack StopWatch / CoreS3)に書き込むスケッチと同じ C++ を WebAssembly にして動かしています。速さは本体とは違います。マイクや傾きの音・値は、この端末の中だけで使い、どこにも送りません。

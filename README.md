大阪・関西万博 2025 のパビリオン **null²**(落合陽一)を見て、
あの「生きている鏡」を手のひらの上で動かしたくて書いた Arduino スケッチ集です。

丸い 466×466 の AMOLED を持つ **M5Stack StopWatch** が主なターゲットですが、
**CoreS3 / CoreS3 SE**(320×240)でも画面いっぱいに動きます。多分。

## 入っているもの

まず [**NullMenu**](NullMenu/) をおすすめします。
5つ全部が入っていて、本体で好きなものを選んで動かせます。

!\[NullMenu](docs/nullmenu.png)

* **ボタンA** … つぎへ / **ボタンB** … きめる / 左右になぞってもえらべます
* 動かしているとき **ボタンB を長押し** すると、いつでもメニューに戻ります

選ばれた1つだけがメモリを確保して動き、切り替えるときに全部返すので、
何度行き来しても増えていきません。

### NullEye

!\[NullEye](docs/nulleye.gif)

鏡の立方体。3つの面それぞれに違う景色が映り込み、膜が波打って像が液体金属のように流れます。
中央には、輪郭からぐねぐね波打つ白い眼。色は 青 → 白 → 赤 → 白 とゆっくり巡り、
数秒おきに眼まるごとまばたきします(たまに2回続けて)。触るとその場でひとつ瞬きます。

!\[NullEye](docs/nulleye.png)

* **ボタンA 短押し** … 時間帯(朝 / 昼 / 夕方 / 夜)
* **ボタンA 長押し** … 灯りの色(万博 / 青緑 / 赤金 / 白銀)
* **ボタンB** … 画面の明るさ
* **なぞる** … 膜が指についてぬるっと流れる。横に払うと立方体が回る
* **押し続ける** … 指のまわりで渦を巻く
* **タップ** … 眼がまばたきし、パッと光って波が膜を走る

## 動かすには

### 必要なもの

* **ボード**: M5Stack StopWatch(丸い 466×466 AMOLED / ESP32-S3R8)
または CoreS3 / CoreS3 SE(320×240)
* **Arduino IDE 2.x**
* ボードマネージャー **M5Stack 3.3.7 以降**
(環境設定の「追加のボードマネージャのURL」に
`https://static-cdn.m5stack.com/resource/arduino/package\_m5stack\_index.json`)
* ライブラリ **M5Unified 0.2.15 以降** と **M5GFX 0.2.21 以降**

### 手順

1. このリポジトリをダウンロード(緑の **Code** → **Download ZIP**)して展開
2. 使いたいスケッチのフォルダごと Arduino のスケッチブックに置く
(フォルダ名とファイル名が同じである必要があります: `NullEye/NullEye.ino`)
3. Arduino IDE で開き、ボードに **M5StopWatch**(CoreS3 なら **M5CoreS3**)を選ぶ
4. 書き込む

## しくみ

ESP32-S3 でフルスクリーンをぬるぬる動かすために、どのスケッチも同じ骨格でできています。

* **重い計算は1フレームに1回だけ**。色は「距離ごとの色の表」や「まわりの景色の絵」に焼いておき、
1ピクセルあたりは *足し算2回 + 表引き* で済ませます(ESP32-S3 換算でおよそ 13〜16 命令/px)
* **膜のうねり**は 8px 間隔の粗い格子の上だけで計算し、ピクセル間は整数の足し算で補間します
* **画面は8行ずつの帯**に分け、2つのコアが交互に描いて、描けた帯から順に DMA で送ります
* 最初の3秒が目標 fps に届かなければ、自動で 2×2 ピクセルの軽いモードに落ちます

各スケッチの冒頭に「調整用」のまとまりがあります。
うねりの大きさ、渦の速さ、リングの本数、色などはそこの数値だけで変えられます。
